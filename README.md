
# Lumi Grace — Skincare Website

A modern, elegant skincare storefront built for **Lumi Grace**, featuring a Vitamin C Serum product page, interactive shopping cart, wishlist, and WhatsApp-based checkout.

## Live Website

**[Visit Lumi Grace](https://lumigrace.netlify.app)**

## About the Project

Lumi Grace is a responsive skincare website designed to provide customers with a simple and convenient shopping experience. The website showcases the brand's Vitamin C Serum through a clean, premium-inspired interface with a cream, black, and gold color palette.

## Features

- **Product Showcase:** Display of Lumi Grace Vitamin C Serum.
- **Shopping Cart:** Add products, remove individual items, clear the cart, and view the subtotal.
- **Wishlist:** Add or remove the product from the wishlist.
- **WhatsApp Checkout:** Prepare an order message with customer and delivery details.
- **Product Quantity Selection:** Select the desired quantity before adding products to the cart.
- **Ingredient Information:** Dedicated section presenting the serum's listed ingredients.
- **Responsive Styling:** CSS styling designed for different screen sizes.
- **Local Storage:** Retains cart and wishlist selections in the customer's browser.

## How WhatsApp Checkout Works

1. Select the product quantity.
2. Add the product to the shopping cart.
3. Enter the required delivery details.
4. Select the WhatsApp checkout button.
5. Review the generated order message and send it to the seller.

The website does not process online payments or automatically manage orders.
